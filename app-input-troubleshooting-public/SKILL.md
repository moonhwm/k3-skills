# 输入框修复指南（app-input-troubleshooting）
> 定位：「输入法正常，但某个应用/网页的输入框无法输入」类问题的**系统性排查技能**。**不处理**输入法本身损坏（如系统级输入法消失、无法切换语言），此类问题走系统设置/重装输入法。

## 核心排查框架：五层漏斗

任何输入框异常，按以下五层逐层过滤，每层确认后再下一层，禁止跳层。

### Layer 1：确认问题边界（30 秒）
**目标**：搞清楚「谁不行、谁行、什么时候开始的」。
| 检查项 | 操作 | 预期结果 | 异常含义 |
|---|---|---|---|
| 同应用其他输入框 | 在应用内找搜索框/设置页/其他输入框测试 | 全部不行=应用级问题；部分行=特定组件问题 | 组件级 Bug |
| 同输入法其他应用 | 打开记事本/Word/浏览器地址栏测试 | 全不行=输入法问题（本技能不管）；部分行=应用兼容问题 | 应用兼容 |
| 网页版 vs 客户端 | 同一服务试网页版和桌面客户端 | 客户端不行网页行=客户端渲染层问题；都不行=输入法对该域名/技术栈不兼容 | 渲染/兼容 |
| 其他输入法测试 | 切换到系统自带输入法（微软拼音/macOS拼音）测试 | 第三方输入法不行自带行=输入法兼容；全不行=系统级 | 输入法兼容 |
| 近期变更 | 问用户：最近更新系统/软件/装新软件了吗？ | 有变更=高度怀疑变更引入 | 变更回退候选 |
**决策**：
- 若「全应用全输入法都不行」→ **转系统输入法修复**（非本技能范围）
- 若「只有特定应用不行」→ 进 Layer 2
- 若「只有特定输入法不行」→ 进 Layer 3

### Layer 2：应用级排查（2 分钟）
**目标**：修复应用本身的输入焦点/权限/缓存问题。
**通用操作（全平台）**：
1. **重启应用**（完全退出再开，不是最小化）
2. **检查输入框焦点**：多点几次输入框，看光标是否正常闪烁；有时焦点没真正进去
3. **切换窗口大小**：最大化/还原/拖动边缘改变大小——刷新渲染层
4. **清除应用缓存**（不丢数据）：
   - Windows：`%LOCALAPPDATA%/<应用名>/` 删 Cache/GPUCache
   - macOS：`~/Library/Caches/<应用名>/`
   - 移动端：设置→应用管理→清除缓存（不要点清除数据）
5. **重装应用**（终极但有效）：卸载→重启设备→官网下载最新版重装
**Windows 特有**：
6. **以管理员身份运行**：右键应用图标→「以管理员身份运行」
7. **兼容模式**：右键→属性→兼容性→勾选「以兼容模式运行」→选 Windows 8
8. **高 DPI 缩放**：右键→属性→兼容性→更改高 DPI 设置→勾选「替代高 DPI 缩放行为」→选「应用程序」

### Layer 3：输入法兼容排查（3 分钟）
**目标**：解决输入法与特定应用的兼容性。
**微软拼音（Windows 11 最常见）**：
1. **兼容模式（解决率最高）**：   设置→时间和语言→语言和区域→中文→语言选项→微软拼音→键盘选项→常规→**拉到最下面**→打开「**使用以前版本的微软拼音输入法**」→**重启电脑**
2. **ctfmon 服务重启**：   `Win+R` 输入 `ctfmon` 回车，重启输入法服务进程
3. **关闭输入法高级功能**：   微软拼音设置→关闭「智能英文」「V模式」「人名输入」等实验性功能
**搜狗/QQ/百度等第三方输入法**：
1. 输入法设置→打开「兼容模式」或「传统模式」
2. 关闭「智能英文」「云输入」「V模式」等高级功能
3. 彻底卸载第三方输入法，用系统自带输入法测试——排除第三方输入法冲突
**macOS**：
1. 系统设置→键盘→输入法→关闭「自动切换到文稿输入法」
2. 终端执行 `killall InputMethod` 重启输入法服务

### Layer 4：系统级冲突排查（5 分钟）
**目标**：找出拦截键盘输入的安全软件/插件/工具。
**常见冲突源 checklist**：
- [ ] **安全软件**：360/火绒/Windows Defender→关闭「键盘防护」「输入保护」
- [ ] **密码管理器**：LastPass/Bitwarden/1Password→禁用浏览器插件
- [ ] **广告拦截**：uBlock/AdGuard→禁用后测试
- [ ] **划词/OCR 工具**：Snipaste/QQ截图/天若OCR→退出
- [ ] **按键宏工具**：AutoHotkey/按键精灵/Quicker→退出
- [ ] **游戏覆盖层**：NVIDIA Overlay/MSI Afterburner→关闭
- [ ] **浏览器插件**（仅网页版问题）：逐一禁用排查
- [ ] **企业安全软件**：深信服/奇安信等终端管理→联系 IT
**Windows 系统更新回退**：若问题出现在近期 Windows 更新后：设置→Windows 更新→更新历史记录→卸载最近的质量更新

### Layer 5：跨平台/跨模型特殊场景
**Web 应用输入框问题**：
1. 换浏览器测试（Chrome→Edge→Firefox）
2. 无痕模式测试（排除插件冲突）
3. 检查浏览器控制台报错（F12→Console）
4. 禁用硬件加速：浏览器设置→系统→关闭「使用硬件加速」
**移动端（iOS/Android）**：
1. 切换输入法（系统自带→第三方→自带）
2. 锁屏再解锁（重置输入状态）
3. 检查应用权限：设置→应用→键盘/输入法权限
4. 卸载重装应用

**跨 AI/模型交接场景**（如 Kimi↔元宝）：输入框问题可能出现在特定 AI 客户端——按同样五层漏斗，但 Layer 2 增加「换网页版测试」作为首要步骤。

## 快速决策树
```
用户：输入框打不了字
│
▼  Layer 1：其他应用能输入吗？
├── 全都不行 → 转系统输入法修复（非本技能）
└── 只有这个应用不行 → Layer 2
│
▼  Layer 2：重启/清缓存/管理员权限/兼容模式 有效？
├── 有效 → 解决
└── 无效 → Layer 3
│
▼  Layer 3：换系统自带输入法测试
├── 自带输入法可以 → 第三方输入法兼容问题 → 开兼容模式/关高级功能
└── 自带也不行 → Layer 4
│
▼  Layer 4：关闭安全软件/插件/工具
├── 有效 → 定位冲突源
└── 无效 → Layer 5（跨平台特殊/重装/反馈官方）
```
## 真实案例库（供参考对照）
| 案例 | 现象 | 根因 | 解决方案 |
|---|---|---|---|
| Kimi 客户端+网页版 | 微软拼音无法输入，浏览器地址栏正常 | Windows 11 新版微软拼音与 Kimi 渲染层不兼容 | 打开「使用以前版本的微软拼音输入法」+ 重启 |
| 某企业微信 | 搜狗拼音候选框不弹出 | 企业安全软件拦截输入法注入 | 联系 IT 加白名单 |
| Chrome 某网页 | 只能打英文，中文完全失效 | 广告拦截插件拦截了输入法 JS 事件 | 禁用 uBlock 对该域名拦截 |
| VS Code | 中文输入延迟 3 秒 | GPU 渲染与输入法冲突 | 关闭硬件加速/更新显卡驱动 |

## 输出规范

排查结束后，向用户输出：
1. **根因判定**（哪一层的问题）
2. **已尝试步骤**（按漏斗顺序列）
3. **最终解决方案**（具体操作）
4. **预防建议**（避免复发）
5. **如未解决**：收集信息（系统版本/应用版本/输入法版本/最近变更）→ 反馈官方
