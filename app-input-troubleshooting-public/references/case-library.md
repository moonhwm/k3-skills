## 案例 1：Kimi Windows 桌面端+网页版无法输入中文拼音
**平台**：Windows 11
**现象**：微软拼音在 Kimi 客户端和网页版均无法输入中文，但浏览器地址栏、记事本正常。
**排查过程**：
1. Layer 1：浏览器地址栏正常 → 输入法本身没问题；只有 Kimi 不行 → 应用兼容问题
2. Layer 2：管理员运行/兼容模式/高 DPI 缩放均无效；清缓存无效
3. Layer 3：切换到系统自带输入法测试 → 微软拼音本身也无法输入 → 非第三方输入法问题
4. Layer 4：关闭安全软件无效
5. Layer 5：Windows 更新后突然出现 → 怀疑系统变更
**根因**：Windows 11 新版微软拼音与 Kimi 的输入框渲染层存在兼容性 Bug。
**解决方案**：设置 → 时间和语言 → 语言和区域 → 中文 → 语言选项 → 微软拼音 → 键盘选项 → 常规 → 打开「**使用以前版本的微软拼音输入法**」→ **重启电脑**。
**预防**：Windows 大版本更新后，若多个应用出现输入异常，优先检查输入法兼容模式。
**验证人**：机主（用户本人），2026-08-27

## 案例 2：企业微信搜狗拼音候选框不弹出
**平台**：Windows 10
**现象**：搜狗拼音在其他应用正常，但在企业微信内候选框完全不显示，盲打可出字。
**排查过程**：
1. Layer 1：其他应用正常 → 非输入法全局问题；只有企业微信不行 → 应用级
2. Layer 2：重启企业微信/清缓存无效
3. Layer 3：切换到微软拼音 → 微软拼音正常 → 搜狗特定兼容问题；开启搜狗兼容模式无效
4. Layer 4：关闭火绒/360 无效；但发现公司统一安装了深信服终端管理
**根因**：企业级安全软件（深信服）拦截了搜狗拼音向企业微信的注入。
**解决方案**：联系 IT 将「搜狗拼音」和「企业微信」加入安全软件白名单；或换用微软拼音。
**预防**：企业环境优先使用系统自带输入法，避免第三方输入法被安全软件拦截。

## 案例 3：Chrome 某网页只能输入英文
**平台**：Windows 11 + Chrome
**现象**：在特定网页（React 开发的在线表单）无法切换中文，始终输出英文。
**排查过程**：
1. Layer 1：记事本/Word 正常 → 输入法没问题；只有该网页不行 → Web 特定问题
2. Layer 2：刷新页面/清缓存无效
3. Layer 3：Edge 打开同一网页正常 → Chrome 特定问题
4. Layer 4：逐一禁用 Chrome 插件 → 禁用 uBlock Origin 后恢复
**根因**：uBlock Origin 拦截了该网页的输入法相关 JavaScript 事件。
**解决方案**：uBlock Origin → 设置 → 白名单 → 添加该域名；或换用其他广告拦截器。
**预防**：广告拦截插件设置白名单，避免拦截表单交互脚本。

## 案例 4：VS Code 中文输入延迟 3 秒
**平台**：macOS + VS Code
**现象**：在 VS Code 内输入中文，候选框延迟 3 秒才出现，其他应用正常。
**排查过程**：
1. Layer 1：其他应用正常 → 非系统级；只有 VS Code 不行 → 应用级
2. Layer 2：重启 VS Code/重装无效
3. Layer 3：换系统自带输入法 → 同样延迟 → 非输入法问题
4. Layer 4：关闭所有插件 → 无效
5. Layer 5：发现关闭「硬件加速」后恢复
**根因**：VS Code 的 GPU 渲染与 macOS 输入法服务存在时序冲突。
**解决方案**：VS Code → 设置 → 搜索「disable hardware acceleration」→ 勾选；或更新显卡驱动。
**预防**：开发工具/编辑器遇到输入延迟，优先尝试关闭硬件加速。

## 案例 5：iOS 微信第三方输入法无法弹出
**平台**：iOS 17 + 搜狗输入法
**现象**：在微信内点击输入框，搜狗输入法键盘不弹出，系统自带键盘正常。
**排查过程**：
1. Layer 1：系统自带键盘正常 → 非系统级；只有搜狗不行 → 输入法兼容
2. Layer 2：重启微信/重装搜狗无效
3. Layer 3：检查权限 → 搜狗「完全访问」已开启
4. Layer 4：发现 iOS 17.1 更新后出现问题
**根因**：iOS 17 对第三方输入法的安全沙盒收紧，部分应用内需要重新授权。
**解决方案**：设置 → 通用 → 键盘 → 键盘 → 搜狗 → 关闭再开启「允许完全访问」→ 重启微信。
**预防**：iOS 大版本更新后，重新检查第三方输入法权限设置。
