# 跨平台输入框排查速查表（cross-platform-input-guide）v1.0（2026-08-27）

本文件覆盖 macOS/iOS/Android/Web 平台的输入框异常排查，配合 SKILL.md 五层漏斗使用。

## macOS

### 输入法服务重启
- 终端：`killall InputMethod`
- 或：活动监视器 → 搜索「InputMethod」→ 强制退出

### 系统设置排查
- 系统设置 → 键盘 → 输入法 → 关闭「自动切换到文稿输入法」
- 系统设置 → 键盘 → 输入法 → 编辑 → 取消勾选「使用大写锁定键切换...」

### 应用权限
- 系统设置 → 隐私与安全性 → 辅助功能 → 确认问题应用有权限
- 系统设置 → 隐私与安全性 → 输入监视 → 确认输入法有权限

### 安全软件
- CleanMyMac/MacKeeper 等「优化工具」可能拦截输入法 → 卸载或加白名单

## iOS/iPadOS

### 基础排查
1. 切换输入法：地球图标切换系统自带/第三方
2. 锁屏再解锁：重置输入状态
3. 强制关闭应用：上滑退出→重新打开
4. 重启设备

### 权限检查
设置 → 通用 → 键盘 → 键盘 → 确认应用有「完全访问」权限（第三方输入法需要）

### 已知问题
- iOS 17+ 部分应用对第三方输入法支持不完整 → 换系统自带输入法测试

## Android

### 基础排查
1. 切换输入法：通知栏下拉→选择输入法
2. 清除应用缓存：设置→应用→问题应用→存储→清除缓存（不丢数据）
3. 切换键盘：设置→系统→语言和输入法→当前键盘→换 Gboard/系统自带

### 权限检查
设置 → 应用 → 问题应用 → 权限 → 确认没有禁用「键盘」相关权限

### 开发者选项（高级）
设置 → 系统 → 开发者选项 → 关闭「不保留活动」（防止后台杀死输入法）

## Web 通用

### 浏览器排查
1. 换浏览器（Chrome→Edge→Firefox→Safari）
2. 无痕/隐私模式测试
3. 禁用所有插件
4. 清除站点数据：F12→Application→Clear storage

### 控制台检查
F12 → Console → 筛选「input」「ime」「composition」相关报错

### 硬件加速
设置 → 系统 → 关闭「使用硬件加速」（Chrome/Edge 常见解决方案）

### 特定技术栈
- **React 应用**：可能缺少 `onCompositionStart/End` 事件处理 → 前端 Bug
- **Canvas 渲染**：输入法无法定位 → 需要自定义 IME 位置
- **Shadow DOM**：输入法事件穿透问题 → 浏览器兼容性问题

## 跨 AI 客户端特殊场景
当问题出现在 AI 客户端（Kimi/元宝/ChatGPT 桌面端）时：
1. **先测网页版**：同一账号登录网页版测试输入
   - 网页版正常 → 客户端渲染层问题 → 清缓存/重装客户端
   - 网页版也不行 → 输入法对该域名/技术栈不兼容 → 换输入法/开兼容模式
2. **客户端特有排查**：
   - 完全退出（不是最小化）→ 任务管理器结束所有进程 → 重开
   - 检查客户端版本是否最新
   - 查看客户端是否有「兼容模式」设置
