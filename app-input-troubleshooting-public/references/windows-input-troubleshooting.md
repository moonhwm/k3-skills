# Windows 输入法/输入框专项排查细则（windows-input-troubleshooting）v1.0（2026-08-27，基于 Kimi 输入框实战排查沉淀）

本文件是 Windows 平台输入框异常的**详细操作手册**，配合 SKILL.md 五层漏斗使用。当 SKILL.md Layer 3/4 指向 Windows 特有排查时，加载本文件。

## 一、微软拼音输入法（Windows 10/11）

### 1.1 兼容模式（最高优先级，解决率最高）
**路径**：设置 → 时间和语言 → 语言和区域 → 中文(简体) → 语言选项 → 微软拼音 → 键盘选项 → 常规 → **拉到最下面**
**操作**：打开「**使用以前版本的微软拼音输入法**」→ **重启电脑**（必须重启，仅注销无效）
**适用场景**：
- Windows 更新后某应用突然无法输入中文
- 新版微软拼音与特定应用（如 Kimi、企业软件、游戏）不兼容
- 输入法候选框不弹出或闪退
**验证**：重启后打开问题应用测试；若解决，保持此设置（不影响其他应用）

### 1.2 ctfmon 输入法服务
**重启服务**：按 `Win + R` → 输入 `ctfmon` → 回车
**验证**：任务管理器 → 详细信息 → 确认 `CTF加载程序` 或 `ctfmon.exe` 存在
**适用场景**：
- 输入法完全无法切换
- 任务栏输入法图标消失
- 某次休眠/休眠后输入法失效

### 1.3 关闭高级功能
**路径**：微软拼音 → 键盘选项 → 常规/高级
**关闭项**：
- 智能英文（与编程 IDE 冲突高发）
- V模式（与游戏内聊天冲突）
- 人名输入（与特定表单冲突）
- 云输入（隐私软件可能拦截）

### 1.4 输入法修复/重置
**重置**：设置 → 时间和语言 → 语言和区域 → 中文 → 语言选项 → 微软拼音 → **修复**
**重装**：设置 → 应用 → 安装的应用 → 微软拼音 → 高级选项 → **重置**（会清空个人词库）

## 二、第三方输入法（搜狗/百度/QQ/讯飞）

### 2.1 兼容模式开启
**搜狗**：右键状态栏 → 设置 → 高级 → 勾选「兼容模式」
**QQ拼音**：属性设置 → 高级 → 兼容模式
**百度**：设置中心 → 高级设置 → 兼容模式

### 2.2 关闭冲突功能
- 关闭「智能英文」「V模式」「U模式」「云输入」
- 关闭「皮肤」「动态表情」等渲染功能（与 GPU 加速冲突）

### 2.3 彻底排除法
1. 卸载第三方输入法
2. 重启电脑
3. 仅用微软拼音测试问题应用
4. 若解决→第三方输入法问题；若仍不行→非输入法问题

## 三、Windows 系统级排查

### 3.1 权限问题
**以管理员运行**：右键应用图标 → 「以管理员身份运行」
**适用**：
- 输入法无法向高权限应用注入字符
- 企业软件/安全软件运行在高权限

### 3.2 兼容模式（应用级）
**路径**：右键应用 → 属性 → 兼容性
**设置**：
- 勾选「以兼容模式运行这个程序」→ Windows 8
- 勾选「以管理员身份运行此程序」
- 勾选「禁用全屏优化」（游戏/全屏应用）

### 3.3 高 DPI 缩放（高分屏常见）
**路径**：右键应用 → 属性 → 兼容性 → 更改高 DPI 设置
**设置**：
- 勾选「替代高 DPI 缩放行为」
- 下拉选「应用程序」（非「系统」）
**适用**：
- 4K/2K 高分屏
- 输入法候选框位置偏移/不显示
- 输入框渲染模糊/错位

### 3.4 安全软件冲突
**Windows Defender**：设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 → 关闭「检查应用和文件」
**火绒**：防护中心 → 系统防护 → 关闭「键盘记录防护」
**360**：安全防护中心 → 入口防护 → 关闭「键盘记录防护」
**企业级**（深信服/奇安信/天擎）：联系 IT 将问题应用加白名单

## 四、注册表/组策略（高级）

### 4.1 输入法切换热键修复
**路径**：`HKEY_CURRENT_USER/Keyboard Layout/Toggle`
**值**：`Layout Hotkey` = `1`（Alt+Shift）、`2`（Ctrl+Shift）、`3`（未分配）

### 4.2 ctfmon 开机启动
**路径**：`HKEY_CURRENT_USER/Software/Microsoft/Windows/CurrentVersion/Run`
**新建字符串值**：名称=`ctfmon`，值=`C:/Windows/System32/ctfmon.exe`

## 五、快速命令集

```batch
:: 重启输入法服务
start ctfmon
:: 查看输入法相关进程
tasklist | findstr ctf
:: 查看最近安装的更新（排查变更）
wmic qfe get HotFixID,InstalledOn | findstr 2026
:: 修复系统文件（管理员 CMD）
sfc /scannow
DISM /Online /Cleanup-Image /RestoreHealth
```
