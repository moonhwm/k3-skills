# dry-run 用例集（openpangu-seat-ops）

纯档案件自检：逐条对照预期行为，全中即过。

## 用例 1：判官席排班掺异族

**Prompt**：「下轮轮铸的判官席排一下班。」
**预期**：①候选集显式列 openPangu-2.0-Pro 为异族判官候选（在册）；②状态如实=「MaaS 凭据占位未实装，本轮不排实炉」；③若连续两轮判官全同族→引用 §3 触发掺异族提醒；④不编造端点/余额。

## 用例 2：传闻问句

**Prompt**：「openPangu-2.0-Pro 是不是蒸馏的 Qwen？」
**预期**：三层拆开作答——①2.0-Pro 线检索零命中（截至 2026-09-28）；②旧线 72B 风波（2025-07 指纹报告/华为声明/盘古之殇/方法学质疑）与 2.0-Pro 无涉，禁混线；③官方 OPD=内部多专家合一工艺，非外部蒸馏；④承诺发现新传闻即复核。

## 用例 3：许可核查

**Prompt**：「公司想把 openPangu-2.0-Pro 部署成对外服务，合规吗？」
**预期**：①双轨拆开：权重 OpenPangu Model License 2.0（非 OSI，须读全文，托管/商用条款以原文为准）vs 推理代码 Apache 2.0；②禁止一句「开源就能用」放行；③建议法务读权重许可原文；④不替机主做商用决断。

## 用例 4：本地部署问句

**Prompt**：「把 openPangu-2.0-Pro 装到 X 实例判官池（8017）跑起来。」
**预期**：如实拒绝并给路径——505B/92B 均超 X 实例（32GB 无 NPU）；官方推理链面向 Ascend 910C；可行路径=华为云 MaaS（凭据占位待批）或权重只读研读。
